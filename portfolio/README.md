Do not replace this with “client”, “delivered”, “approved”, “live for DawServe”, or publish customer logos, screenshots, endorsements, contracts, or non-public information without written permission.

Before using this site for outbound sales:
1. Confirm permission to link this demo publicly, or replace it with an entirely unbranded independent concept.
2. Add a dedicated, approved business email or other reliable inbound contact CTA. Current contact CTA links to public GitHub profile only.
