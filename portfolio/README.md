# Abdulrahman Studio — Independent Developer Portfolio

Standalone bilingual AR/EN web portfolio for an independent developer. **This is not an agency website or a DawServe property.**

## Project state

- **V3 candidate branch:** `design/abdulrahman-studio-v3-independent-20261123`.
- **Published base branch:** `portfolio/independent-web-developer-20261123`.
- Render Static Site `abdulrahman-studio` publishes `portfolio/` from the base branch. **Do not merge V3 without visual approval.**
- No build system required: `index.html`, `styles.css`, `app.js`, `assets/`.
- QA: `node --test portfolio/qa.test.mjs` and `node --check portfolio/app.js`.
- V3 art direction and review evidence: [V3 Visual QA](V3_VISUAL_QA.md).

## Identity and positioning

V3 uses warm off-white, near-black and electric cobalt blue to distinguish the developer's identity from the DawServe case study.

- Hero introduces Abdulrahman, independent web development and business value.
- Work section contains DawServe as **one independent proposal concept**; its imagery and colors do not define the portfolio identity.
- Service rows, process and contact support additional projects without redesigning the home page.
- Arabic RTL, English LTR, responsive navigation, accessible focus and reduced-motion preferences.
- Work visual is a **stylized composition based on authentic DawServe concept media, not an actual website screenshot**.

## Truthfulness / launch guardrails

The DawServe project is not described as a paid client delivery, an official approved website, or a real WordPress production deployment. Its public demo is a static preview.

Before using the portfolio for prospecting:

1. Obtain written permission to feature the DawServe name, project photography and public demo URL or switch to an unbranded concept.
2. Replace the provisional GitHub profile contact action with an approved direct business contact.
3. Verify mobile Safari, core routes, image loads, locale switching and performance on a deployed preview.
4. Review applicable commercial/contracting obligations.
5. Only remove `noindex` and other crawl restrictions when the portfolio is ready for public discovery.

No fabricated testimonials, paid-client claims, conversion metrics, analytics, forms or tracking are included.
