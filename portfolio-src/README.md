# Signature V5

Owner-approved Magic Patterns design, exported as a standalone React production bundle. Source: `Portfolio.tsx`. The stylesheet is `../portfolio/styles.css`; the published HTML and compiled bundle are in `../portfolio/`.

Rebuild: from this directory run `npm install` then `npm run build` (Node version compatible with Vite 8). Run `npm test` for source and release checks. Commit the rebuilt bundle together with the source. The existing Render static site publishes the `portfolio/` directory without an installation step; existing preview routes are preserved.

Design screenshots are served by Magic Patterns CDN. DawServe screenshot is from the concept site; other images are design previews, not verified live screenshots. Independent concepts are not official client deliveries. Noindex is intentionally retained.
